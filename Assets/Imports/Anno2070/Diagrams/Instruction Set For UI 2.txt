Anno 2070's core rule is verified: the tier page initially exposes **finished-product selectors**; selecting one reveals the directly buildable production buildings for that chain. ([Golem][1])

## A. Give Codex this

> Implement the Anno 2070-style Production section of Moonlight's Construction Menu.
>
> Do not build a generic building grid. Production must be a two-state UI:
>
> **Collapsed**
>
> * Show one button per production line.
> * Button represents the final good/output, not an individual building.
>
> **Expanded**
>
> * Clicking a production-line button expands a production-chain panel upward.
> * Keep the production-line selector row visible.
> * Show every building in that selected chain as individually clickable construction buttons.
> * Show dependency connectors between buildings.
> * Selecting another production line replaces the currently expanded chain.
> * Leaving the civilization page, changing faction, selecting Infrastructure or Ornaments must clear the expanded production chain.
>
> Use data-driven definitions, not hardcoded page UI.
>
> Required model:
>
> ```csharp
> ConstructionPageDefinition
> ProductionLineDefinition
> ProductionNodeDefinition
> ProductionConnectionDefinition
> ```
>
> `ProductionLineDefinition` needs:
>
> ```text
> Id
> DisplayName
> OutputIcon
> UnlockCondition
> Nodes[]
> Connections[]
> ```
>
> Each node needs:
>
> ```text
> BuildingData
> Column
> Row
> UnlockCondition
> ```
>
> Use explicit `Column` and `Row` coordinates rather than trying to invent an automatic graph-layout algorithm. The chains are deliberately composed UI layouts and need predictable placement.
>
> Support these layouts:
>
> ```text
> [A]
>
> [A] -> [B]
>
> [A] -> [B] -> [C]
>
> [A] --\
>        -> [C]
> [B] --/
>
> [A] -> [B] --\
>               -> [D]
> [C] ----------/
>
> [A] --\
>        -> [C] -> [E]
> [B] --/
> [D] ----------> [E]
> ```
>
> Connections must support:
>
> ```text
> Horizontal
> MergeFromAbove
> MergeFromBelow
> VerticalJoin
> ```
>
> Do not make every connector a unique sprite. Construct connectors from reusable horizontal/vertical pieces and elbows.
>
> The expanded panel must calculate its height from occupied rows. A simple chain should stay short; a branched chain should push the sections beneath it downward.
>
> Locked production lines remain visible but disabled/greyed. Once their population requirement is reached they become interactable and receive the existing new-unlock notification treatment.
>
> Clicking an actual building node must invoke the existing Moonlight building-placement pipeline. The production-chain framework must not contain placement logic.
>
> Build the framework first with placeholder icons and populate the following Tycoon definitions.

## C. Exact six-page Production behavior

The six Tycoon construction pages are Infrastructure, Workers, Employees, Engineers, Executives, Ornaments. Anno explicitly uses up to six population-specific construction tabs. ([Anno 2070][2])

### 1. Infrastructure

**Collapsed**

```text
Infrastructure
(no Production selector row)
```

**Expanded**

```text
Never expands a production chain.
```

Infrastructure has its own direct categories/buttons.

### 6. Ornaments

```text
No Production section.
No expandable production chain.
Switching here collapses any currently open chain.
```

That last behavior is worth explicitly implementing: Ubisoft even patched a bug where a production chain incorrectly remained displayed after switching to the Ornament tab. ([PC Gamer][7])

## Minimum asset set

Do **not** make dozens of special connector images.

You need:

```text
ProductionLineButton frame
Selected ProductionLineButton frame
Locked frame/overlay

BuildingButton frame
BuildingButton hover/selected
BuildingButton locked overlay

Chain background / right-facing arrow panel

Horizontal connector
Vertical connector
90-degree elbow
T-junction

Final-good icons
Individual building icons
```

The most important implementation decision is: **explicit node coordinates + reusable connector primitives**. Don't let Codex build a fancy automatic graph solver for something Anno solves as a tightly authored GUI.
