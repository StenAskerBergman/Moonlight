(1) Item System
----------------------------------------------------------------------------------
 Meta Description of the entire system, and all of its 
 sub systems. First off, we are using MVC Model here.

 MVC (Model-View-Controller) design pattern:

    Model: Storage 
    (Stores data & state of items)

    View: Inventory 
    (Interactions & interface of data)

    Controller: StorageManager 
    (Events & Manipulations of the data)

> Model
Storage: This is the fundamental system where items, 
resources, or data are stored. Think of it like a 
database or a container. 

Its primary concern is the efficient, safe, and 
organized storage of items. It doesn't necessarily 
care how the items are accessed, only that they are 
stored correctly.

Therefore Invalid Storage should result in an error;
A error the Storage Manager is responsible to handle.

> View
Inventory: This is the interface or the access point 
for the player. It's what the player sees & interacts 
with. 

The inventory provides a representation of what
is in the storage, and when the player wants to do 
something (like use an item, move an item, etc.), the 
inventory communicates with the Storage Manager to 
make that happen.

> Controller
Storage Manager: This is the intermediary that knows 
how to perform operations on the storage. It can add 
items, remove items, check for capacity, etc. 

The Storage Manager essentially controls and manages 
the storage, ensuring that all operations are valid 
and that the integrity of the storage is maintained.

        [RequireComponent(typeof(Island))]


public Dictionary<ItemType, int> GetTotalResourcesOnIsland()
{
    Dictionary<ItemType, int> totalResources = new Dictionary<ItemType, int>();
    foreach (Base playerBase in island.GetComponentsInChildren<Base>()) // Assuming each player base has a 'Base' component
    {
        Inventory baseInventory = playerBase.GetComponent<Inventory>();
        if (baseInventory)
        {
            foreach (KeyValuePair<ItemType, int> entry in baseInventory.GetItems())
            {
                if (totalResources.ContainsKey(entry.Key))
                {
                    totalResources[entry.Key] += entry.Value;
                }
                else
                {
                    totalResources.Add(entry.Key, entry.Value);
                }
            }
        }
    }
    return totalResources;
}
